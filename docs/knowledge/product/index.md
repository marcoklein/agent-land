# Product

Product knowledge lives here as OKF notes, versioned with the code it describes. A note's `status` field is its pipeline state: `draft` → `stable` → `deprecated`. `verified` records a human review.

* [Goals](goals/) — what agent-land is for, and why it exists
* [Features](features/) — capabilities in flight, each with user stories and acceptance criteria
* [Designs](designs/) — approved technical designs, the handoff from product to implementation
* [Pipeline](pipeline.md) — how an outcome becomes shipped code, and where the human gates sit
